How to read this

Each bar is a context: a conversation the model reads. A Skill or Agent call that opens a new context is a message to a new bar, and its result comes back as a dashed line. Rows run in time order, not to scale.

Contexts that never overlap share a column. The top of each bar shows the tokens its model calls spent:

  • new: input that was not cached, plus cache writes
  • cached: history read from the prompt cache, far cheaper
  • out: model output

The call tree lists the same calls with their costs. A bold row is a context, with its totals. With every tool call on, the rows inside it are its steps, and they add up to those totals:

  • Each step shows the model call that came right after it: new for what it read that was not cached yet, cached for the history it read again, out for what it wrote next.
  • prompt is the context's first model call. A row with an arrow (←) is where a context it started returned.
  • The bar under a number starts where the previous step's bar ended, so each column fills from 0 to the context's total.
  • A down arrow (↓) marks calls made together: the model call after them is on the last one.

Click a context's totals to dim every other context; click again, or press Esc, to bring them back. Hover over a number for its exact value. Click a row for its arguments and result.
