How to read this

Each row is one session recorded on this branch, oldest first. The token columns add up to the bold row. They count what the model calls of a session spent:

  • new: input that was not cached, plus cache writes
  • cached: history read from the prompt cache, far cheaper
  • out: model output

Click a session to open its diagram and call tree, and click again to close it. Hover over a number for its exact value. Times are in UTC.
